# Pressure Chains

Purpose: maintain offensive initiative without attack-stop-reset behavior.

## PC-01 Straight Miss -> Forward Landing -> Secondary Attack

Trigger:
attacker throws a long straight/kick that misses because defender shifts off line.

Changed state:
attacking limb/body has forward momentum; one foot may land ahead.

Continuation:
use the new forward stance to attack again or frame the defender.

Do not:
retract completely, return to original mark, pause, then attack.

Examples by family:
- boxing: missed rear straight -> lead side loaded -> lead hook / pivot pressure.
- kickboxing: missed round kick -> kicking foot lands forward -> hands continue.
- long-fist: long kick lands forward -> opposite hand uses preserved rotation.

## PC-02 Guard Compression -> Shorter Tool

Trigger:
first strike forces defender into high/closed guard.

Changed state:
defender's hands/forearms occupy upper line; space narrows.

Continuation:
attacker shortens weapon:
- body punch,
- elbow,
- palm,
- shoulder,
- low kick,
depending style.

Core rule:
the second attack exists because the first changed guard geometry.

## PC-03 Retreating Receiver -> Step-Matched Pursuit

Trigger:
impact/pressure forces defender backward.

Changed state:
distance is opening while attacker has forward initiative.

Continuation:
attacker follows with one short step timed to receiver's recovery step.

Avoid:
sprinting past opponent or freezing while receiver retreats.

## PC-04 Parried Limb -> Opposite-Side Attack

Trigger:
attacker's first limb is redirected across/outside line.

Changed state:
that shoulder/side becomes extended or occupied.

Continuation:
attacker uses opposite hand/leg only if base and torso make it available.

Can also cause initiative flip if defender owns the new line.

## PC-05 Low Attack -> Upper Opening

Trigger:
low kick/sweep/body attack changes defender's weight or guard.

Changed state:
defender lifts leg, lowers hand, bends torso, or shifts base.

Continuation:
next attack targets the actual opening created, not a pre-scripted combo.

## PC-06 Close Entry -> Contact Pressure

Trigger:
attacker successfully collapses long range.

Changed state:
forearms/shoulders/arms touch; long kicks are no longer clean.

Continuation:
use style-valid short tools:
- boxing pocket punches,
- Muay Thai elbow/knee/clinch,
- Nanquan bridge/palm,
- Baji elbow/shoulder,
- wrestling body lock.

## AI risks
- two unrelated attacks begin at once,
- receiver finishes reaction before attacker moves,
- both fighters reset feet,
- combo becomes symmetrical left-right choreography with no tactical reason.
