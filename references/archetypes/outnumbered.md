# Outnumbered Fight

## Engine
One fighter manages multiple attackers by controlling line, spacing and sequencing.

## Core rule
Do not let every attacker attack simultaneously.

Use:
- funneling,
- obstruction,
- one attacker blocks another,
- angle change,
- short incapacitation,
- moving escape line.

## 3-phase structure
1. Encirclement threat.
2. Line creation: protagonist moves so attackers queue or interfere.
3. Breakout or temporary control.

## Spatial ledger
Track each attacker separately:
- screen position,
- distance,
- current state,
- whether active / recovering / blocked.

## Useful directing
- wide anchor,
- single attacker insert,
- foreground attacker partial,
- re-establish wide after local exchange.

## Failure modes
- enemies politely wait with no spatial reason,
- all attackers rush simultaneously and bodies merge,
- hero teleports between targets,
- screen direction becomes unreadable.

## AI guidance
For short AI clips, 3 attackers is usually safer than large crowds.
