# Environment-Driven Fight

## Engine
Objects and architecture continuously alter routes, distance or attack opportunities.

## 3-phase structure
1. Establish usable objects/geometry.
2. First interaction changes movement or attack line.
3. Environment damage / displacement creates a new tactical state.

## Valid environment roles
- obstruction,
- support,
- rebound,
- elevation,
- trap,
- breakable surface,
- visual occlusion,
- route divider.

## Useful combinations
- recovery-failure-chains
- clinch-throw-transitions
- wuxia-spatial-chains

## Directing
- environment impact,
- occlusion cut,
- damage insert,
- landing/recovery detail.

## Rule
Object interaction must be causally useful.

Bad:
fighter touches random table because it exists.

Good:
failed kick drives attacker into table edge, forcing hand support and creating counter window.

## Failure modes
- props appear spontaneously,
- broken objects reset,
- debris explodes before impact,
- object interaction hides body continuity.
