# Counter Duel

## Engine
One fighter intentionally gives the opponent initiative, reads the attack, and converts mistakes into precise counters.

## 3-phase structure
1. Draw attack: defender presents range/line.
2. Conversion: parry/slip/check/angle changes attack state.
3. Counter result: short decisive counter changes initiative or spacing.

## Initiative
Attacker appears active first.
Defender becomes active only when a real opening is created.

## Spatial behavior
Usually smaller movement than pursuit fights.
Angle changes matter more than long travel.

## Useful combination refs
- counter-conversions
- recovery-failure-chains

## Useful directing
- relation shot,
- eye-line trigger,
- attack-to-camera,
- forearm collision insert,
- result shot.

## Failure modes
- defender countering before attack actually arrives,
- magical anticipation,
- repeated “dodge then punch” with no body mechanics,
- every beat ending in neutral reset.
