# Fight Scene Archetype Router

Fight Scene Archetypes define the **macro dramatic engine** of the fight.

They do not replace:
- martial-art style,
- atomic mechanics,
- combination causality,
- directing grammar.

Use one primary archetype for a short sequence. Add a secondary archetype only when the scene clearly changes mode.

## Direct routing

## Archetype selection

Choose based on **scene engine**, not genre label.

Example:
“武侠” is not an archetype by itself.

A wuxia scene may be:
- pursuit-fight,
- pressure-duel,
- peer-duel-escalation,
- environment-driven,
- wuxia-courtyard.

## 10-second rule

For ~10 seconds:
- one primary archetype,
- roughly 3 kinetic phases,
- one clear escalation,
- one readable end-state.

Do not stack 4 archetypes into 10 seconds.

## Archetype output

Each archetype should provide:
- dramatic engine,
- phase structure,
- initiative behavior,
- spatial behavior,
- suitable combination patterns,
- suitable directing patterns,
- failure modes.
