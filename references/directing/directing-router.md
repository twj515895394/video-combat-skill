# Action Directing Router

This layer controls **how combat is photographed and edited**, not which martial-art techniques exist.

Load only the directing references needed for the current action problem.

## D0 — Shot objective first

Before choosing a camera technique, identify the shot's primary information:

- spatial relationship,
- body mechanics,
- attack trajectory,
- impact contact,
- defense / interception,
- momentum result,
- environment damage,
- landing / recovery,
- subjective threat,
- emotional reaction.

One shot should have one primary job and at most one secondary job.

## D2 — Style profile

If the user asks for a specific action-film tradition or named filmmaker reference, route to:
`style-profiles/style-profile-index.md`

A Style Profile:
- changes shot grammar, rhythm, staging emphasis and visual treatment,
- does **not** replace Base Combat Style,
- does **not** override physical continuity,
- must be translated into abstract mechanisms,
- must not copy one exact film scene shot-for-shot.

## D3 — Load budget

For one short 5-15 second fight:
- 1 directing router,
- usually 1-2 shot-technique files,
- optionally `shot-pattern-library.md` when concrete shot-card selection is needed,
- optionally 1 style profile.

Do not load the shot-pattern library merely because cinematic shooting is requested; use it when the director needs concrete reusable shot modules.

Do not load every directing file.

## Precedence

Body mechanics and spatial continuity > shot readability > style profile > flourish.

If a stylish angle hides foot support, attack line or landing in a mechanically important beat, use the readable angle.
