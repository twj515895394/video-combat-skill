# Lau Kar-leung — Grounded Martial-Arts Display Reference

Use this as a grounded martial-arts cinematography/choreography profile, not as a claim that every Lau film uses one identical grammar.

## Source basis

Criterion's *Once Upon a Time in China* essay contrasts Lau-family grounded combat influence with more weightless wire-dependent action and describes a rock-solid realism in the martial-arts treatment before later Yuen-family contributions.

Source:
https://www.criterion.com/current/posts/7604-once-upon-a-time-in-china-the-complete-films-past-master

## Profile DNA

### 1. Technique is the spectacle
The camera should allow viewers to see:
- stance,
- footwork,
- body alignment,
- attack-defense mechanics,
- recovery.

### 2. Full-body proof matters
Do not fragment every exchange into close-ups.

### 3. Physical credibility before visual flourish
Jumps, falls and impacts should retain body weight.

### 4. Style distinction should be visible
Different martial systems should look different through:
- stance,
- range,
- rhythm,
- tools,
not merely costume.

## Useful shot grammar

LK-01 stable full-body two-shot.
LK-02 three-quarter mechanics shot.
LK-03 longer exchange with minimal cuts.
LK-04 close insert only for decisive contact/hand detail.
LK-05 return to full body immediately after detail.

## Best use

- authentic-feeling martial-arts duel,
- Southern styles,
- traditional kung-fu demonstration inside dramatic fight,
- style-vs-style comparison.
