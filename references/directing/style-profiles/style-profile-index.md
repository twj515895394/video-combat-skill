# Action Cinema Style Profile Index

Style Profiles are analytical references for directing grammar.

They do not replace:
- base martial-art style,
- biomechanics,
- spatial continuity,
- shot readability.

## Registered profiles

- New-Wave Hong Kong Wuxia / Tsui Hark reference -> `tsui-hark-new-wave-wuxia.md`
- King Hu rhythmic widescreen wuxia -> `king-hu-rhythmic-wuxia.md`
- Yuen Woo-ping tempo / props / attack-defense choreography -> `yuen-woo-ping-action-design.md`
- Lau Kar-leung grounded martial-arts display -> `lau-kar-leung-grounded-martial-arts.md`
- Sammo Hung practical kinetic action -> `sammo-hung-practical-action.md`

## Translation rule

A named filmmaker or choreographer may be used internally as a reference label.

Final generative prompt should normally translate the profile into abstract mechanisms such as:

- kinetic Hong Kong wuxia,
- aggressive reframing,
- expressive POV insert,
- prop-driven spatial choreography,
- rhythmic widescreen staging,
- grounded full-body martial-arts proof,
- practical impact and weighted stunt movement.

Do not instruct the model merely:
`in the style of [living filmmaker]`.

Do not copy:
- one exact scene,
- exact shot order,
- signature composition,
- dialogue,
- costume,
- character,
- set piece.

Transfer mechanisms, not a specific copyrighted sequence.
