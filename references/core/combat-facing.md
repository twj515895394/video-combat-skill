# Combat Facing

Use when characters inexplicably turn away, attack empty space, or remain back-facing.

## Default facing envelope

During active exchange:
- eyes track opponent,
- chest stays roughly opponent-oriented,
- tactical side-on angles of 20-60 degrees are valid,
- hips may temporarily rotate farther during strikes,
- prolonged back exposure requires explicit cause.

## Valid temporary back-facing

Examples:
- spinning kick,
- pivot under pressure,
- impact-induced turn,
- roll/evasive turn,
- throw rotation.

Every valid turn needs:
`front-facing entry -> rotation cause -> temporary back phase -> reorientation or immediate physically valid continuation`

## Invalid patterns

- "A moves behind B" with no path.
- B does not turn or react while A circles freely.
- A finishes a strike facing away and stays there.
- camera cuts and character orientation flips.
- both characters face the same direction while supposedly exchanging attacks.

## Angle language

Prefer:
- "front-left quadrant"
- "front-right quadrant"
- "outside the lead shoulder"
- "30 degrees off the centerline"
- "chest remains angled toward the opponent"

Avoid vague:
- "around him"
- "to his side"
- "behind him"

## Cross-screen continuity

If fighter A starts screen-left and B screen-right, maintain that relation until a visible crossing event occurs.

A real crossing event requires:
- readable path,
- overlap/occlusion or pass-by,
- both characters reorient,
- next shot re-establishes relationship.

## QC question

At the end of each beat:
Can both characters plausibly see and immediately attack/defend against each other?

If not, either the action intentionally created disengagement or the choreography is broken.
