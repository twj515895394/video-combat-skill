# Aerial Motion

Use for jumps, flying kicks, qinggong, wall steps, vaults and AI failure cases involving floating or synchronized hopping.

## Mandatory aerial chain

`support -> compression -> push-off -> trajectory -> airborne action -> landing -> absorption -> continuation`

## Default one-airborne-subject rule

For short AI-video combat, only one main character should be clearly airborne at a time unless a dual-air exchange is explicitly requested and carefully choreographed.

Grounded opponent should:
- track,
- evade,
- intercept,
- reposition,
- prepare landing attack.

## Push-off

Specify:
- support foot,
- surface,
- knee compression,
- extension direction.

Examples:
- rear foot drives off stone floor,
- left foot plants on low railing,
- right sole briefly plants against pillar.

## Trajectory

Prefer one simple path:
- forward,
- forward-up,
- lateral,
- diagonal-down,
- short rebound.

Avoid combining multiple flips, direction changes and attacks in one short airborne beat.

## Landing

Specify:
- first landing foot,
- second foot if needed,
- knee absorption,
- facing direction,
- residual forward/lateral momentum.

## Qinggong constraint

Cinematic qinggong may exaggerate distance and grace, but should retain:
- visible support,
- short airborne duration,
- clear gravity,
- readable landing.

No hovering unless the user explicitly wants fantasy flight.
